# 汇报 PPT · 交付自检清单（checklist）

> 逐项过；A 结构 / B 内容 / C 视觉 / D 技术 / E 配套。配合 `engines/pptx/SKILL.md` 的代码 QA 与视觉验收。

## A. 结构

- [ ] 场景配方对位：叙事骨架符合 `scenarios.md` 对应场景（课程展示/文献分享/开题/中期/终期/思政/beamer）
- [ ] 系列一致性（开题→中期→终期）：header、配色、结尾页与前期 deck 一致；数据卡同款可对照
- [ ] 页序完整：封面（题目/副标/成员/日期）→ 目录或导航 → 正文 → 总结 → 结尾（致谢+Q&A，极简）
- [ ] 页码：内容页起显示；长 deck（≥25 页）有导航条或节标页眉
- [ ] 无模板占位符残留（队名：/队员：/xxx/TODO/Click to add）

## B. 内容

- [ ] 页标题=结论或判断（beamer 关键帧同）；header 内标题 ≤18 字不截断
- [ ] 页标题语域=书面判断句/名词性栏目名，无聊天腔、设问腔、段子腔（逐页抽查）
- [ ] 一页一个主张；正文页 ≤150 字为宜、卡片化后 ≤330；讲解型/推导页例外需讲稿支撑
- [ ] 关键数字与报告/论文/数据一致；无来源的关键数字 = 不合格
- [ ] 每张图表在讲解词中有着落；演示页有"看什么"提示
- [ ] 中期对照开题、终期对照中期（承诺→兑现→偏差闭环）；成果页有实证（截图/榜单/波形）
- [ ] 思政 deck：逻辑链编号、核心判断条、三案例卡、落到个人收束，四件齐
- [ ] 引用真实：文献编号/URL 可查；"Credit to/来源声明"在 borrowed content 页保留

## C. 视觉

- [ ] 配色：官方轨用模板主题色；自建轨按 `brand.md`（校徽蓝+银杏黄或样本家族），单页 ≤5 色
- [ ] 校徽/校标：版本正确（白版深底/蓝版浅底）、比例正确、安全边距 ≥ 高度 1/4
- [ ] 装饰克制：线稿/银杏单页 ≤3 处；渐变元素单页 ≤2 处且方向一致；无 title 下划线、无彩色边条堆叠
- [ ] 字号阶梯：页标题 20–28pt、正文 12–14pt、注释 ≥10pt（大卡内按填充率放大，见 brand.md §2）；无细字重上投影
- [ ] 每页有视觉锚点；无大空白区靠装饰填充（空白用内容解决）
- [ ] 背景图文字有遮罩；"灰度打印仍可读"抽查 3 页
- [ ] 同页图标风格统一；表格关键行有强调、数字右对齐
- [ ] 多列/对射卡组顶边、底边对齐；列内数量不等时已再平衡，无单列提前收尾留下大空白
- [ ] 卡内文字竖向填充率 ≥2/3 卡高；不足时先放大字号/行距，再考虑缩卡
- [ ] 卡头对齐方式按版式选择（居中/左对齐混用），全册非单一格式
- [ ] 图标/SVG 使用有节制（一页 2–4 枚、同页风格统一）；无 emoji、无文本圈号顶替图标

## D. 技术（engines/pptx 配合）

- [ ] 代码 QA：`scripts/pptx_qa.py` 无 hard fail（占位符/越界），溢出与重叠告警已处理
- [ ] 画布 16:9（33.9×19.1cm）；A1 填充后回读形状几何核对
- [ ] **A1 背景**：背景克隆后确认背景已落位且图片关系有效（`scripts/pptx_bg.py` 已重绑 rId；目录页背景勿套给正文页）
- [ ] 图片压缩：成品 <20MB（美术型 ≤50MB）；无失效图片链接
- [ ] 渲染验收：`scripts/render_preview.py` 出页图（或派 visual-judge）——文本碰撞/溢出/越界清零

## E. 配套交付

- [ ] **讲解词**：每页 30–60 秒成段口语稿（"这页说什么→为什么→下页接什么"），允许适度复述；总时长匹配限定时间
- [ ] 深底 deck 需打印时：附白底版
- [ ] 交付新文件（`<stem>_updated.pptx`），原件未动；中间产物清理

## 使用方式

生成后 agent 按 A→E 自查并报告；视觉部分按 `engines/visual-judge.md` 的提示词逐页验收（有子 agent 则派发）。
