## 2. 反面模式（生成时必须避免）

| 问题 | 样本例证 | 对策 |
|---|---|---|
| 标题被 header 截断 | P-10"四.功能演示与场景案例" | header 标题 ≤18 字 |
| 结尾页塞总结 | P-11 结尾页 333 字 | 总结放倒数第二页；结尾页只留致谢+Q&A |
| 单页形状爆炸 | P-08 p14（44 形状版本大表） | 拆 2-3 页或只留关键列 |
| 代码/截图页零文字 | P-11 代码页（4 字符） | 加"看什么"三行提示或标注框 |
| 连续同构页疲劳 | P-06 CNN 分支 9 页同构、P-14 人物九连页 | 中途插小结/关系图页 |
| 大段文字上墙 | P-14 世界观 350+ 字成段 | 拆要点卡，全文进讲解词 |
| 高密度无讲解预案 | P-09 中位 305 字/页 | 讲解词逐页配齐（该场景的硬要求） |
| 画布超规格 | P-03 双倍宽 67.7cm | 统一 16:9（33.9×19.1cm） |
| 深底未备打印版 | P-02/P-12 深蓝风 | 评审可能打印时补白底版 |
| 图片不压缩 | P-14 46MB | 交付前压图（目标 <20MB） |
| 来源缺失 | 个别样本图表无出处 | 每张关键图有来源行 |

## 3. 系列 deck 一致性（答辩三部曲经验）

同一项目开题→中期→终期：header/配色/结尾页完全一致（P-06/07/15 实证）；数据卡同款升级（0.13237→0.10964）；后期 deck 显式回指前期遗留问题。生成系列时先建立"系列样式卡"（header 几何、配色、页脚、结尾页模板），三场复用。
