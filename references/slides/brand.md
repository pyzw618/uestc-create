### 1.3 渐变使用规则

1. 同色系明度渐变（蓝→深蓝、黄→浅黄）：可用于大面积底纹、封面背景，方向统一。
2. 双色渐变（校徽蓝→银杏黄）：只用于小面积点缀（标题条、装饰条、进度条），面积大会显脏。
3. 正文文字、图表数据系列永不使用渐变色；单页渐变元素 ≤2 处；同一 deck 渐变方向一致。

## 2. 字体与字号阶梯（16 份样本校准）

| 元素 | 规格 |
|---|---|
| 封面主标 | 32–44pt 加粗（中文微软雅黑；西文 Arial/Calibri） |
| 页标题（结论句） | 20–28pt 加粗；header 条内 16–20pt |
| 卡片标题/要点名 | 14–16pt 加粗（橙色或校徽蓝） |
| 正文 | 12–14pt；1.15–1.3 倍行距 |
| 注释/来源/页脚 | 10–12pt（下限 10pt） |
| 大数字卡 | 40–60pt（P-06"0.13237"、P-09"91.5%"） |

- 避免细字重（投影发虚）；层级靠字号+字重+颜色，不换字体；全 deck ≤2 字族。
- CJK 文本框比拉丁等长内容多留 ~15% 宽度余量。
- 字号阶梯是**下限基准**而非上限：高度 >1.6" 的大卡片内，正文按"卡高填充率 ≥2/3"放大字号与行距（正文可至 16–18pt、行距 1.3–1.5）；宁可缩卡也不留"12pt 两行 + 半卡空白"。
- 卡头小标题按版式选对齐：独立对称卡/色块 header 条居中，带正文段落的卡左对齐；全 deck 至少两种处理，不整册一种。

## 3. 版式模式（样本实证）

1. **header 横条**（P-06/07/10/11/15）：深蓝横条（左：校标组合白版；中/右：节标题白字；点缀橙色斜切块）——成电辨识度最高的自建模式。
2. **左侧导航条**（P-16，≥25 页强烈推荐）：节清单常驻左侧，当前节高亮+箭头。
3. **结论标签卡**（P-07）：白卡写发现短句 → 图 → 蓝底白字推论卡，竖直流线。
4. **数字分节页**（P-02）：大号 01/02 + 主题图 + 节名一句话。
5. **提纲回现**（P-01）：每节前重复目录页（长讲座适用）。
6. **章节连缀 header**（P-14）：大节——小节连写于页眉。
7. **页顶节标+页脚页码**（P-12）：灰色小编号"01 · 节名"+ 白卡正文。
8. **双栏对射/多列卡组**：顶边、底边双对齐；两列条目数不等时必须再平衡（增高卡片、把余量吸收进卡内边距、或重新分组），禁止单列提前收尾留白。

## 4. 素材用法（assets/slides/brand/）

完整清单见 `素材索引.md`，核心规则：

1. **版本选择**：`（白色版）`用于深色背景；`（校徽蓝版）`用于浅色背景——用错版本是最低级错误。
2. **校徽**：保持比例，四周留白 ≥ 校徽高度 1/4；不拉伸、不变色、不加特效；封面右上或 header 左侧（P-07/12 实证）。
3. **院徽版式**：左右排版适合页眉/页脚条；上下排版适合封面角落。
4. **装饰元素**：主楼/图书馆线稿用于封面与目录页低透明度装饰（10–25%，P-07 目录页实证）；**银杏叶/银杏枝**适合特色配色点缀（P-12 右下银杏枝；单页 ≤3 处）；校训（"求实求真 大气大为"）用于封面水印或结尾页（P-07 封面校训圆弧水印+结尾页大水印实证）。
5. 背景图上文字必须加深色遮罩（P-09 全屏实景+遮罩为范本）；"灰度打印仍可读"自检。

## 5. 母版数据（A1 程序化填充用）

## 6. 反面清单（样本实证）

- 标题过长被 header 截断（P-10"四.功能演示与场景案例"换行截断）——header 标题 ≤18 字。
- 结尾页塞 300+ 字总结（P-11）——总结放倒数第二页，结尾页极简。
- 单页 44 形状（P-08 版本演进）——拆页。
- 双倍宽画布（P-03 67.7cm）——国内教室投影按 16:9（33.9×19.1cm）。
- 深蓝底 deck 未备白底版——评审需打印时不可读。
