# 汇报 PPT · 场景配方（scenarios）

> 证据来源：16 份参考 PPT（代号 P-01…P-16，精读记录见 `_analysis/notes/slides/`，原件不入包）。
> 每条配方 = 叙事骨架 + 页数区间 + 单页信息密度 + 必备页 + 该场景的加分动作。
> 证据标注：★=≥2 份专属样本；△=单专属样本（补充佐证来自跨场景同款页），使用时保守套用并可向用户确认。

## 0. 通用铁律（所有场景生效，16 份样本共同印证）

1. **页标题写结论或判断**（"三段式流水线将 CPI 降低 32%""装机第一 ≠ 发电量第一"），不写栏目名（"实验结果"）。实证：P-06/09/12 全程结论式；P-05 beamer 的议题式标题是学术场景例外。
2. **一页一个主张**，每页有视觉锚点（图/卡/大数字/框图）；纯文字页只允许出现在提纲、定义、过渡。
3. **单页文字量**：正文页 ≤150 字为宜，硬上限 ~300（卡片化后可到 330，P-02）；推导/文献页例外（P-03/P-13）。本文与 checklist 中"字"一律指汉字字符数。
4. **数据必须可溯源**：图表来源标注（"数据：本实验"或文献编号）；关键数字与报告/论文一致。
5. **讲解词配套**：每页 30–60 秒成段口语稿；页面留白靠讲稿补，不靠堆字。
6. 页码：内容页起显示（封面目录可不显）；长 deck（≥25 页）建议左侧导航条或节标页眉（P-16/P-12）。

## 1. 课程展示 / 项目展示 ★

**证据**：P-10（学校"示范"模板，官方认可叙事）+ P-02（产品化展示）+ P-16（过程汇报）+ P-14（设计类）。

**六节叙事骨架（P-10 示范即官方骨架）**：
封面（队名/队员/时间）→ 目录 → ①背景与定位（痛点卡→定位卡对射）→ ②整体架构（分层文字+全景图）→ ③核心节点说明×N（一节点一页：要点名+解释+截图）→ ④功能演示×N（场景问句做小标题："校园事务：如何办理运动卡"）→ ⑤数据分析（运营数据大字卡）→ ⑥技术总结与展望（优点/缺点对射卡+展望编号三条）→ 结尾 Thank You。

- 页数：13–21 页。密度：60–250 字/页。
- **过程汇报变体**（P-16，软件工程类）：按生命周期组织（需求→概要→详细→测试→维护→管理→演示），配工程度量表（功能点/行数/甘特图）；≥25 页务必左侧导航条。
- **设计类变体**（P-14，游戏/美术）：概述→世界观→图鉴式设定页×N→系统（玩法/规则/关卡/界面）→施行需求；策划叙事允许成段，但 350+ 字必须拆卡。
- **产品化加分**（P-02）：给项目起名+命名故事页；数字分节页（01/02…）；分期规划页；页脚 slogan。
- 加分动作：优缺点对射卡（P-10）；演示页配"看什么"提示（P-11 反例：代码页零文字）。

## 2. 组会 / 文献分享 ★

**证据**：P-12（综述型）+ P-03（逐篇精读型）+ P-13（算法专题型）。

**三种打法按材料选**：
- **综述型**（读了一个方向）：P-12 骨架——封面（核心论点句上封面+关键词行）→ 背景与动机（痛点行+失效模式小卡）→ 分类框架 TAXONOMY（分类树+**分类原则声明**"按'记忆发生了什么变化'分类"）→ 双轴定位（范式时间轴+论文对比表）→ 机制页×N（橙色"核心问题："句驱动）→ 总结。11–15 页。
- **精读型**（深读一篇/一篇为主）：P-03 骨架——任务图解 → 原理 → Research State 时间轴（每论文一句话定位）→ 逐方法页（Core innovation/Limitations 红字对比卡）→ Challenge → References。页题带引用编号（"FastComposer [1]"）。
- **算法专题型**（讲透一个方法）：P-13 骨架——原理推导（公式编号）→ Algorithm 伪代码框 → 实例 → 改进/对比 → 应用；**页脚引文**每页标注出处。
- 通用加分：页题=知识点+[编号]；"核心问题："句驱动页面；中英对照术语（P-12）。
- 密度例外：精读/推导页可 500–900 字（P-03/P-13），但需讲者级熟悉度；普通综述页仍守 150 字。

## 3. 开题答辩 △

**证据**：P-07（专属样本）+ 跨样本佐证：P-06"项目重述"页反向印证开题的"计划"角色；P-15 回指卡证明中期/结题都在核兑现（即开题承诺必须可核）；C-02 的题目分析节（PEAS/环境分类）与 P-07 题目分析页同构——同一项目族的文端互证。

**叙事骨架（P-07）**：封面（题目+副标"开题汇报"+成员名单+日期）→ 目录（编号圆圈+节名）→ 题目概况（竞赛内容/要求/意义一页装下）→ 题目分析（框架卡：PEAS 环形图+维度卡）→ 数据基础统计（标注轴+环形图）→ 数据分析×3（**结论标签卡**：白色卡写发现短句→图→蓝底推论卡给对策）→ 潜在问题（问题卡×3，粗体标题+3-4 行解释）→ 最新现状（技术演进图）→ **技术路线（三阶段卡：数据预处理→模型架构与训练→性能提升与融合，每卡 3-4 行要点）** → 结尾（校训水印+Thank You+Q&A）。

- 页数：13–16 页。核心页是**技术路线三阶段卡**与**潜在问题诚实卡**。
- 加分：数据泄露等风险的预判（P-07"视频连续抽帧导致的数据泄露与'作弊'风险"）；最新现状页展示调研深度。

## 4. 中期答辩 ★

**证据**：P-06（主）+ P-15（终期回指中期，双向印证）。

**叙事骨架（P-06）**：封面（同系列视觉）→ 目录（项目重述/阶段成果/技术路线/面临挑战/后期展望）→ **项目重述**（任务/评测标准含公式/数据集规格——一页让评委免翻开题）→ **阶段成果**（大数字卡"测评最佳成绩 0.13237"+排名卡+排行榜截图圈出自己的位置）→ 路线总览（四模块流程图）→ 分支技术页×N（**方案演变叙事**："初始策略→优化方案"标签卡；技术分析页 3-4 行成段；页尾结论+箭头过渡"因此：……引入↓ Transformer"）→ **面临挑战**（挑战卡，橙色标"难"，诚实列单点故障风险）→ **后期展望**（方向名做页标题，一方向一页）→ 结尾。

- 页数：20–24 页。比开题文字密度高（正文 2-4 行成段）。
- 铁律：**对照开题逐项核**（承诺→兑现→偏差）；成果必须有截图/榜单实证。
- 加分：单类性能雷达图（直言"偏科"）；Top-K 错误样本图组；分支开场页（中心+四角总览）。

## 5. 终期/结题答辩 ★

**证据**：P-15（主）+ P-14（课程答辩变体）+ P-06（对照）。

**叙事骨架（P-15）**：封面 → 项目重述（可省目录）→ **阶段成果进步卡**（"0.13237/第7名 → 0.10964/第5名"同款大字卡，评委一眼看到进步）→ 技术改进页×N（**洞察→验证→对策大箭头页**："仔细观察数据集发现……"橙色 → 验证数据 → 大箭头 ↓ "降维特征工程"；模型改进页：方案名+"具体操作："编号公式行+三图对比+橙色结论句）→ **预判质疑页**（"说明：这个跟我们之前的标签平滑看起来是冲突的，但是……"——主动堵提问）→ **回指卡**（"中期存在的问题：裁剪失败率约2%…终期改进：双视角策略"）→ 六阶段闭环总览 → 结尾。

- 页数：20–24 页，技术密度三部曲最高（卡 4-7 行）。
- 铁律：**完成情况对照开题**；每项改进有消融/对比证据；不回避没做好的（诚实归因来自 B-11 同源纪律）。
- 加分：异构模型角色分工页（"ResNet152：原图（提取纯粹的静态特征）"）；六阶段编号闭环把全部技术串起来。

## 6. 思政展示 △

**证据**：P-09（专属样本，全库思政最高完成度）+ 跨样本佐证：C-08/C-09/C-19 思政论文的"观点—引用—联系实际"叙事与案例卡内容一脉同构（历史案例+当下案例+自身专业）；P-02 的品牌化叙事佐证"主题化呈现"手法。

**叙事骨架（P-09）**：封面（课程名·小组汇报，主题化配色——生态主题用全屏光伏实景+绿）→ 编号小节推进（一~十）穿插：**日常关联 / 实践案例 / 日常行动 / 产业成就 / 青年担当 / 总结展望** → 感谢聆听。

- **必备件**：①结论式大标题（"不是孤立能源事件，而是完整理论逻辑链"）；②编号逻辑链时间轴（理论提出①→战略部署②→政策体系③→实践成果④+逐条说明段）；③**核心判断高亮条**（每页一句绿色横条收束）；④**三案例卡**（同主题三个典型案例，各 4-5 行事迹+数字）；⑤数字反差引入（"装机第一 ≠ 发电量第一"+91.5%/90.8%/接近10%）；⑥落到个人的收束（"美丽中国，我们是行动者"）。
- 页数：15–19 页；密度 250–350 字/页（思政以论述为主，讲解词必须配齐）。
- 加分：权威表述引用（注明出处）；本地/校内案例接地气；配色服务主题（绿色生态/红色党史）。

## 7. 学术报告（beamer 支线）★

**证据**：P-05（LaTeX 源码）+ P-04（同一 deck 编译产物）。

- 适用：数学/化学/理论型课程报告；无设计负担，内容即排版。
- 基线：Madrid 主题 + whale 深蓝配色，aspectratio=169，10pt；隐藏导航符号。
- 惯例：columns 双栏（文字左图右）；帧标题议题式（学术惯例，可与结论式混用——关键帧用结论式）；`\footnote` 贴来源；booktabs 三线表（>15 行用 scriptsize）；mhchem/equation 公式；allowframebreaks 参考文献帧。
- 加分：红字行内标签（"误区澄清：""核心思想："）模拟结论卡（P-04 编译实证）；图题带引用编号（"图 2 元素丰度悖论 [1]"）。
- **编译实测（阶段 5 审查，TeX Live 2025 + XeLaTeX）**：链路完整可用，14 页样例编译通过。四条实战要点：①拿到他人 .tex 常缺图（figs/ 不随源码分发），需按 `\includegraphics` 清单重建占位图；②学术源码常用**多页 PDF 素材配 `page=N, trim=…` 裁切**（P-05 实证：REE.pdf 取第 13 页）——占位 PDF 页数必须 ≥ 所引页码；③占位图用 PIL 生成（matplotlib 带中文文本的 PDF 输出可能令 xdvipdfmx 崩溃）；④编译失败时先 `xelatex -no-pdf` 产出 .xdv，再手动 `xdvipdfmx` 分离定位是排版问题还是图片嵌入问题。

## 8. 讲座/长课程（附注，非学生配方）
