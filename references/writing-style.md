# 写作纪律（writing-style）

> 版本 **v4（阶段 5 终审冻结版）**。生成任何正文性文字（实验报告各节、课程论文、课设报告、思政论文、PPT 页文字、讲解词）**必须先载入本文档**，生成后按 §5 自查清单逐条过。
> 终审结论（阶段 5）：四条正面原则在四类交付物（实验报告/论文/思政/PPT）均有锚例与附加细则支撑（§2.1–2.5）；禁用词表经四轮样本证据校准，从"全面禁用"修正为"频率与语境约束"——真实学生语料中"综上所述"（结论处）与工程术语"闭环控制"属正常用法，禁的是空洞化滥用。

## 0. 总纲

你写下的每一段，读者都是熟悉这门课的老师或同学：他们看惯了实实在在的句子，对空话套话极其敏感。目标是写得像**一个认真做了实验、真的想清楚了的成电学生**在交作业——不是语言模型在完成任务。

## 1. 四条正面原则

### 一、成段成体系

- 以段落为表达单位，每段只讲一件事：主题句起头，中间用证据推进，结尾落到结果或衔接下一层。
- 段与段之间要有**真实的**逻辑承接：因果（"因此实测中……"）、转折（"然而与理论值相比……"）、递进（"在此基础上进一步……"）、对照（"与文献 [2] 的做法不同……"）。承接词必须承载真关系，不是装饰。
- 只有真正并列的可枚举项（步骤、物料清单、超参数表）才用列表；本该成段的分析禁止拆成 bullet 碎片。
- 检查方法：把段落顺序打乱后读不通，才叫"成体系"；随便换序仍通顺，说明段落间没有真实逻辑。

### 二、拒绝专有名词罗列

- 每个术语第一次出现，用一句话交代"它是什么、在这里为什么需要它"。
- 一句话里最多引入一个新概念；禁止连续堆砌名词或缩写。
- 深入浅出的固定动作：**先说人话（现象/类比/例子），再给术语**。
  例："示波器上看到的波形在 3.3V 处被削平，这就是限幅——输入超出单片机引脚耐压时，内部钳位二极管把电压'顶'住了。"
- 概念引入的顺序服从问题展开的顺序，不按名词表展开。

### 三、深入浅出地分析

- 分析遵循"**现象 → 机制 → 证据 → 结论**"：先说观察到什么（带数字），再解释为什么（有因果链），最后下结论（带边界条件）。
- 每个结论必须挂靠证据：每个"因此"前面要有数据或事实；没把握的写"可能的原因是……，可以通过 xx 验证"，而不是含糊其辞。
- 敢写局限：具体写哪里没做好、可能为什么、下一步怎么办。一份承认"在 10kHz 以上波形失真明显，推测与采样率不足有关"的报告，远比"仍存在一些不足"可信。
- 类比和例子要贴课程场景（电路、信号、代码报错），不用生造的宏大比喻。

### 四、去除 AI 味

**禁用清单（出现即改写）：**
- 空洞套话：综上所述（每篇 ≤1 次且仅在结论）、总而言之（同前）、不难发现、由此可见、值得注意的是（作为废话开头时）、具有重要意义、为……提供了有力支撑、随着……的不断发展、迈上了新台阶。
- 报告文学腔：赋能、抓手、闭环、深度融合、全方位、多角度、层次化、体系化（除非确有所指——"闭环控制""闭环反馈"等工程术语合法）。
- 机械连接：整段的"首先/其次/再次/最后"、无内容的"一方面/另一方面"。
- 空洞拔高与排比堆叠、设问自答开场；无对照数据的"极强的/卓越的/完美的"。
- 数字模糊："性能明显提升""显著改善" → 必须落到"准确率从 82.3% 提升到 87.1%（+4.8 个百分点）"。

**形态禁令：** 正文不用 emoji；不滥用加粗；不用"——"连缀的排比长句；段落长短应有自然差异。

**语气校准：** 客观、克制、平实；多用"本实验/本文/实验中"，少用"我/我们觉得"；承认不足要具体，不抽象自责；遇到意外结果照实写——"与预期相反"往往是全文最有价值的段落。

## 2. 分场景附加细则

### 2.1 实验报告（阶段 2 依 16 份样本回填，细则见 `lab-report/sections.md` 与 `lab-report/discipline.md`）

- **语气分层**：分析类节（原理/步骤/结果分析/结论）客观克制，用"本实验/本设计"；**总结及心得体会切换第一人称"我"**，与全文客观语气分工——这是学生报告的真实双轨制。
- **原理节**：概念→公式→人话解释（"熵的实际意义表示是……"）；并落到本实验参数（"本实验中取 R=1kΩ，故时间常数为 1ms"）；禁止照抄教材定义凑字数。
- **结果分析**：数字先行（"准确率 96.00%，仅 3 个样本预测错误"），多视角归因（数据→超参数→实现，每条因果完整）；每张图后必有一段解读，禁止裸贴图；反常现象不回避（"验证损失始终低于训练损失，这一现象可能源于两个因素：一是……二是……"）。
- **负结果诚实范式**：结果差时——对照基准→量化差距→有序归因并标主因（"造成这一结果的可能原因包括：……，这是模型性能不佳的主要原因"）→改进逐条对治。失败的归因比成功的吹捧更有价值。
- **误差分析**：现象→编号归因→改善方法三段式，硬件类归因到器件参数。
- **数据表格**：让表格说话，正文只解读关键趋势；结论数字精确到百分位并给样本量与错误数。
- **结论**：回应实验目的逐条闭环；"综上所述"每篇至多 1 次且只在结论开头。
- **心得**：每个收获配一个具体事件（踩坑→排查→解决→领悟）；"这让我明白……"句式有效但每篇 ≤2 次。
- **改进建议**："手段+目的"成对，写具体技术名；没有实质建议就如实写"无"。

### 2.2 课程论文 / 课程设计报告（阶段 4 依 20 份样本回填，细则见 `course-papers/writing.md`）

- **摘要四要素**（问题/方法/结果/结论）各一句话内完成；数模摘要按问题分条且含数值结果；删掉一切铺垫。
- **引言**漏斗式：背景（带事实数字）→ 已有工作 → 缺口 → 本文做什么怎么做；结尾一段"本文拟通过…探讨…"路线声明。
- **正文论证**：每节回答一个明确的小问题；案例具体到时间地点数字（"1934年11月，湖南汝城县沙洲村"），不写"许多地方"；每段 1–2 处引用为度，编号与文末一一对应。
- **结论 ≠ 摘要**：写"做出了什么、意味着什么、还剩什么"；理论类给出明确条件或关系式。
- **课程设计报告**额外：选型必有对比与理由（"选择 X 而非 Y，主要基于以下考量"）；"完成内容↔课程知识点"映射表是加分件；遇到的问题与解决方法独立成节。
- **结题报告**：问题分层（数据/模型/策略/推理）与改进措施逐层对应；结尾"参与体会"切第一人称。

### 2.3 思政类论文 / 报告（阶段 4 回填）

- 基本单元是"**观点 — 引用（文献/原著/权威表述）— 联系自身专业或生活的实例**"三件套，缺一不可；每节至少完整走一遍。
- 引用必须真实且逐字核对（领导人原著、经典文本）；转述标注"参见"；**禁止编造引文**。
- 联系实际的事例优先用用户本人专业与经历（计算机×生成式AI、电气×双碳…），具体到一次课程、一个项目、一段新闻事实。
- 论证句式："第一，…。第二，…。第三，…。"用于真并列；挑战段"一是…二是…三是…"后接逐条对策。
- 副标题范式："从'A'到'B'——××的实践演进与当代价值"（意象锚点+点题）。
- 联系实际时用真实具体的事，不喊口号；结尾落在"自身如何做"，不空谈意义；"综上所述"每篇 ≤1 次且仅在收束段。
- 2000 字级短论文可不设章节编号，靠设问过渡（每篇 ≤2 处）；3000 字级以上用"一、引言…五、结语"中文章节。

### 2.4 PPT 页文字（阶段 3 依 16 份样本回填，细则见 `slides/scenarios.md`、`slides/checklist.md`）

- **页标题写结论或判断**（"三段式流水线将 CPI 降低 32%""装机第一 ≠ 发电量第一，更不等于稳定第一"），不写栏目名（"实验结果"）；beamer 学术帧可用议题式，关键帧仍宜结论式。
- 正文短句、数据前置；一页一个主张；不整段搬运报告原文。
- 卡片文字两级结构：**粗体要点名 + 一句解释**（"搜索空间 Search Space：……"），卡内 3–5 行为宜。
- 核心判断句上高亮条（"核心判断：……"）；页面间的过渡用结论+箭头（"因此：……引入↓ X"），让翻页有叙事动力。
- 图表页：图为主角，文字只留"看什么"≤3 条；每张关键图有来源行。
- 思政页：结论式标题+编号逻辑链+落到个人的收束句（"美丽中国，我们是行动者"式，但必须具体）。
- 密度上限：正文页 ≤150 字为宜、卡片化 ≤330；推导/文献页例外但需讲稿支撑。

### 2.5 讲解词（配 PPT 交付）

- 口语化的成段文字，按"这页说了什么 → 为什么/机制 → 下一页接什么"组织；每页 30–60 秒的量。
- 允许适度重复上一页要点（真实演讲如此）；写完读一遍，拗口就改短句。
- 数据页先报结论再报数字（"我们拿到了 0.13237 的成绩，排第 7——这个数字意味着……"）；
- 被提问概率高的页（预判质疑页）讲解词里带一句主动说明。

## 3. 通用操作规则

- 数字与单位：统一格式（有效位数一致、单位用国标符号），前后一致。
- 引用：成电论文用 GB/T 7714；引用必须真实可查，**禁止编造**；不确定的文献让用户提供或标注"待核实"。
- 首次出现的外文缩写给全称（"卷积神经网络（CNN）"），此后用缩写。
- 表述中性：不用绝对化断言（"完美解决""彻底消除"），用可证伪的表述。

## 4. 快速对照卡（生成前默念）

1. 这段的主题句是什么？——说不出就重写。
2. 这个术语解释了吗？——没有就先解释。
3. 这个结论有证据吗？——没有就补数据或降语气。
4. 这句删掉会不会更干净？——会就删。

## 5. 自查清单（生成后逐条过）

1. 是否存在 §1 禁用清单中的套话？
2. 随机抽三段：有主题句吗？有具体证据（数字/现象/引用）吗？段间有真实承接吗？
3. 每个术语首次出现有解释吗？有连续名词堆砌吗？
4. 结论都有证据挂靠吗？"明显/显著"都换成数字了吗？
5. 列表使用是否克制（只用于真正并列项）？
6. 读起来像认真学生的作品，还是像模型输出？——找一句"最像 AI"的话改掉它，重复直到找不到。

- 版本记录：v0（阶段 1 种子，2026-09-28）；v1（阶段 2 回填实验报告细则：语气分层/负结果范式/频率化禁用词校准——真实样本证明"综上所述"在结论处属正常学生用语，改为每篇 ≤1 次，2026-09-28）；v2（阶段 3 回填 PPT 与讲解词细则：结论式标题的思政实证、卡片两级结构、过渡箭头句、讲解词三段式，2026-09-28）；v3（阶段 4 回填论文与思政细则：案例具体性、引用纪律、思政三件套落地、副标题范式、结语落自身行动，2026-09-28）；**v4（阶段 5 终审冻结，2026-09-28）**：确认四原则在四类交付物均有锚例；"闭环"等词补工程语境例外；禁用清单、语气分层、自查清单定稿。后续修订走 §6 维护规则（新样本证据驱动），不再随阶段重写。
