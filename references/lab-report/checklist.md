# 实验报告 · 交付自检清单（checklist）

> 逐项过，任何一项不过先修再交付。A 组=结构，B 组=内容，C 组=格式，D 组=合规。

## A. 结构

- [ ] **骨架核对**：报告所用骨架与用户模板/课程要求逐节对齐（节名、编号风格、起始编号——注意"六、"续写型与"一."点号型）
- [ ] 合并型报告：每个实验骨架完整、顺序正确；挑战实验标题与基础实验区分明确
- [ ] 封面字段与 `config/user.yaml` 一致：姓名、学号、学院、专业、指导教师、日期/时间地点（按模板要求）
- [ ] 结对/小组报告：全体成员姓名学号齐全、顺序与用户给出的一致
- [ ] 摘要框（如有）：≤400 字，含"做了什么+关键机制+验证结论"
- [ ] 评分栏/签字栏保留且**留空**
- [ ] 章节编号连续无跳号、无重复（对照骨架逐节检查）

## B. 内容

- [ ] 每节有实质内容：原理与课程匹配且落到本实验参数；无整段教材抄写
- [ ] 超参数齐全（epoch/lr/batch/优化器/损失函数/器件型号/仪器精度），任务书要求"与源码对应"的已注明出处
- [ ] 结果数字具体：指标有精度、有样本量、对比有差值；无"明显提升/效果很好"裸奔
- [ ] 每张图后有一段解读；每张表在正文被引用；图表编号连续、图题图下/表题表上
- [ ] 误差/失败分析：现象→原因→改善（或归因）三段完整；失败结果按负结果范式（对照→差距→主因标注→对治）
- [ ] 结论回应实验目的；未注水（课程允许时可短）
- [ ] 心得有第一人称与具体踩坑事件，未整段复述结果分析
- [ ] 改进建议"手段+目的"成对；没有实质建议时如实写"无"
- [ ] 引用文献真实可查、格式统一（GB/T 7714 或课程惯例）；网页链接完整
- [ ] 同一论述全文只出现一次；未发现整段自我重复

## C. 格式与文字

- [ ] 版式与 `format.md` 一致（A4、边距、字体字号、标题加粗、正文缩进）
- [ ] 中文 eastAsia 字体已设置（`scripts/cjk.py fix` 或生成时设 `w:eastAsia`）
- [ ] 单位符号规范（V/mA/ms/%）、有效位数全文一致
- [ ] 错别字清零（重点：阈值/幅值/松弛/寄存器 等易错词）
- [ ] 无未写完的句子；无"TODO/待补/xxx"占位
- [ ] 代码块：可复制文本（非截图）、关键注释保留、语法完整；绝对路径已移除

## D. 合规

- [ ] 全文（含文件名、代码、表格）无真实姓名/学号以外的任何人信息；示例身份用占位符
- [ ] 用户原始数据文件未被修改；交付新文件
- [ ] 截图/波形图如含个人信息（用户名、主机名）已打码或替换
- [ ] 文件名符合用户课程要求（未要求时用"课程_实验N_学号后四位"风格并与用户确认）

## 使用方式

生成完成后，agent 按顺序自查并在最终回复中报告"A/B/C/D 全过"或列出未过项与原因。
