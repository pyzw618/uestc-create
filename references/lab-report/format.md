# 实验报告 · 版式配置（format，定稿）

> 版本：定稿（阶段 2）。数据来源：官方《标准实验报告.doc》解析（`assets/lab-report/layout_params.json`）+ 16 份样本版式印证。
> 本文档回答"长什么样"；每节写什么见 `sections.md`，怎么写见 `discipline.md`。

## 1. 页面设置（官方标准模板实测）

| 项 | 值 |
|---|---|
| 纸张 | A4（21.0 × 29.7 cm） |
| 页边距 | 上下 2.54 cm，左右 3.17 cm（Word"常规"） |
| 分节 | 封面（两页）与正文分节；页码按课程要求（多数模板正文不显式编页） |

## 2. 官方骨架（12 节，逐字保留标题写法）

**封面页一**：`电子科技大学 ××学院`（大字）→ `标 准 实 验 报 告`（36pt 加粗居中，字间空格）→ `（实验）课程名称` 填写行 → `电子科技大学教务处制表`（12pt 加粗居中）。
> "实验"可整体替换为"实践"（课程名含"实践"时，B-02~05），封面标题同步变"标 准 实 践 报 告"。

**封面页二**：`电 子 科 技 大 学`（22pt 加粗）→ `实 验 报 告`（26pt 加粗）→ 填写行（14pt 加粗）：`学生姓名 / 学号 / 指导教师`、`实验地点 / 实验时间`。

**正文十二节**（节标题 14pt 加粗，"一、……："冒号结尾；正文 12pt 宋体，首行缩进 2 字符）：

```
一、实验室名称：        二、实验项目名称：      三、实验学时：
四、实验原理：          五、实验目的：          六、实验内容：
七、实验器材（设备、元器件）：
八、实验步骤：          九、实验数据及结果分析：
十、实验结论：          十一、总结及心得体会：
十二、对本实验过程及方法、手段的改进建议：
```

**结尾**：`报告评分：`（10.5pt）、`指导教师签字：`——留空。

## 3. 样本校准的版式变体（按用户模板选用）

| 变体 | 版式要点 | 样本 |
|---|---|---|
| 源码内嵌扩展 | 在"八、实验步骤"后插"九、实验源码"，后续节号顺延（十结果分析/十一结论/十二心得/十三建议）；源码用等宽小字号（10.5pt/Consolas），保留注释 | B-06 |
| 摘要框 | 封面页二下方加"任务及完成情况摘要(不超过400字)"框 + 指导老师评语表（可含分值权重行） | B-12 |
| 结对/小组封面 | 填写行重复（每名成员一行"学生姓名/学号"）或成员表格；小组课设可加"小组成员："表格 | B-12、B-01/14、B-13 |
| 课设信息块 | 封面后接"报告目录 + 课程名称/课程设计名称/测试日期/测试设备/报告评分"信息块（设备写到版本号） | B-01/14 |
| 表格版封面 | 封面为单表格（课程名称/学院/专业/姓名/学号/指导教师/日期） | B-15 |
| 表格竖排大标题封面 | 实验中心版式（"计算机专业类课程 实验报告"竖排大字 + 信息表） | B-07 |

## 4. 字体字号基线

| 元素 | 规格 |
|---|---|
| 封面标题 | 36pt 加粗居中（标 准 实 验 报 告）；第二页校名 22pt / 报告名 26pt |
| 填写行/节标题 | 14pt 加粗 |
| 正文 | 12pt（小四）宋体，西文 Times New Roman，1.3 倍行距，首行缩进 2 字符 |
| 表格/图注 | 10.5pt（五号）；表题表上方、图题图下方，编号"表N/图N"全文连续 |
| 代码 | 等宽字体（Consolas/Courier New）10.5pt，可复制文本；长代码进附录 |

用 python-docx 生成时**必须设置 `w:eastAsia`**（否则中文走默认字体）；可直接用 `python scripts/cjk.py fix <file.docx> --ea 宋体` 一次性设置（方法见 `engines/docx/SKILL.md` §1）。

## 5. 生成方式选择

| 方式 | 适用 | 说明 |
|---|---|---|
| **复制官方模板填充**（首选） | 用户走标准 12 节骨架 | 以 `assets/lab-report/标准实验报告.docx` 为底版，段落匹配替换；保真度最高 |
| 程序构建 | 教师自定骨架 / 六节压缩骨架 / 课设骨架 | 按本文 §2–§4 参数用 python-docx 构建；标题用 Heading 样式 |
| 用户模板填充 | 工作区有老师模板 | 以用户模板为底版，只填内容不动格式 |

**混合骨架判别（老师模板只是部分改动时）**——很多老师模板实为官方 12 节的改名或局部增删，不要当"全新骨架"程序构建。对照本文 §2 数节名匹配数：

| 判据 | 处理 |
|---|---|
| ≥10 节同名/近义同序 | 视为官方骨架的改名/增删：以**用户模板**为底版填充，节名与编号逐字沿用 |
| 6–9 节匹配，或结构明显重组（如结果与结论合并） | 视为**教师自定骨架**：程序构建，节名编号照用户模板，版式参数用本文 §4 基线 |
| ≤5 节匹配（六节压缩 / 课设型） | 按对应骨架族处理（见 `sections.md` §0 骨架族谱） |

三条铁律：① 节名与编号一律以用户模板为最高优先；② 用户模板缺失的官方节（如缺"实验器材"）**不擅自补**，除非课程要求明确要求；③ 判不准时问用户一句"哪个课程、有没有样例报告"，不要猜。

骨架底版：`assets/lab-report/标准实验报告骨架.docx`（占位符版，见同目录 README）。
