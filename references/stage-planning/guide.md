# 分期项目规划 · 开题/中期/结题指导（guide）

> 证据来源：P-06（中期答辩）、P-07（开题答辩）、P-15（终期答辩）三部曲 + C-02（结题报告）交叉印证。
> **本路线只做对话内规划，不产出任何文件**；需要文档转 C 路线，需要汇报转 A 路线。

## 0. 总规律：承诺 → 兑现 → 下一步

每一期本质上都在回答同一组问题，只是侧重不同：

| 期 | 一句话定位 | 评委只关心 | 时间视野 |
|---|---|---|---|
| 开题 | 论证"值得做 + 能做成" | 想清楚没 | 向后看（计划） |
| 中期 | 证明"在轨" | 做出来没、偏了多少 | 当前+短期 |
| 结题 | 证明"做成了" | 做成了多少、还剩什么 | 向前回顾 |

三期共用同一条纪律：**口径一致**。任务描述、评测指标、数据规模在中期与结题必须沿用开题的定义（三部曲实证：logloss 指标从开题用到结题；成绩卡 0.13237→0.10964 同款对照）。改口径必须显式说明原因。

## 1. 开题：论证"值得做 + 能做成"

**内容划分（六块）**：

1. **背景与意义**：解决什么问题、为什么现在做、应用场景。落到具体（数据集、竞赛、课程工程），不写"随着…的飞速发展"。
2. **目标与内容**：可检验的目标（指标+基线）＋任务分解。目标写成"达到什么可测量状态"，如"mAP@0.5 ≥ 0.80"而非"做出一个好的模型"。
3. **技术路线/方案**：分阶段卡片（P-07 三阶段范式：数据预处理→模型架构与训练→性能提升与融合），每阶段 3-4 行要点，阶段间有交付物衔接。
4. **可行性**：已有基础（上过的课、跑通过的基线、可用的设备与数据）、风险点与预案。**主动写潜在问题**（P-07 实证：数据泄露风险、类不平衡）——预判风险是加分的诚实，不是示弱。
5. **进度安排**：倒排时间线，节点精确到周；每个节点有可交付物（数据集就绪/基线跑通/中期检查/论文初稿）。
6. **预期成果与分工**：成果形式（系统/报告/竞赛成绩）；小组分工与贡献比例口径（与后续 B-12 式封面一致）。

**常见坑**：目标不可测量；技术路线写成教科书综述（没有自己的路径）；可行性只写"我们学过"；时间线只有里程碑没有交付物。

## 2. 中期：证明"在轨"

**内容划分（五块）**：

1. **项目重述**：一页把任务/指标/数据重述清楚（P-06 范式）——评委不翻开题材料。
2. **阶段成果（核心页）**：**大数字卡**（当前指标 + 对照开题目标的差值）+ 实证截图（榜单/波形/系统运行）。P-06 范式："测评最佳成绩 0.13237 / 排名第 7"。
3. **对照开题逐项核**：承诺了什么→完成情况→偏差与原因。**偏差必须显式**（"中期数据集扩至 8000 张，实际 6214 张——调低数量保标注质量"），遮掩偏差是中期答辩最大减分项。
4. **技术分析**：做了什么改进、为什么有效（消融/对比）；方案演变叙事（"初始策略→问题定位→优化方案"）。
5. **面临挑战 + 后期展望**：诚实的难点卡（标"难"）；展望按方向列出（一方向一页），方向与开题承诺衔接。

**常见坑**：只报喜不报忧；成果没有实证截图；挑战写得太抽象（"数据不足"→应写"远端小目标仅占 2.3%，AP 0.61"）。

## 3. 结题：证明"做成了"

**内容划分（十节，参照 C-02）**：题目概况 → 题目分析 → 探索性数据分析/需求分析 → 最新研究现状/相关工作 → **项目进展情况（对照开题总核）** → 方案/模型设计 → **结果分析** → **主要问题分析（分层）** → **拟改进措施（与问题逐层对应）** → 参与体会（第一人称）。

- 成果呈现与中期同款数字卡升级对照（P-15：0.13237/第7 → 0.10964/第5）。
- **回指中期遗留问题**（P-15 范式："中期存在的问题：…；终期改进：…"）——三期闭环的最后一环。
- 预判质疑页：主动解释容易被追问的表面矛盾。
- 问题分析与改进措施**分层对应**，不许问题写了四层、改进只有笼统一段。

## 4. 时间线建议（以一学期项目为例）

```
第1-2周   选题调研 + 开题（技术路线卡 + 风险清单）
第3-4周   数据/需求就绪（节点交付物：数据集说明）
第5-8周   基线跑通（节点：基线指标）→ 改进实验
第9周     中期检查（成果卡 + 偏差说明 + 挑战卡）
第10-14周 攻坚改进（对照中期挑战逐条）
第15周    结题报告（C 路线）+ 答辩 PPT（A 路线）
```

弹性：竞赛型项目以提交截止倒排；课程型以教学周为锚。

## 5. 与 A/B/C 的衔接

| 规划产出 | 落地路线 |
|---|---|
| 开题的技术路线卡、成果卡模板 | A 路线（开题/中期/结题配方） |
| 中期成果的实验数据 | B 路线（实验报告） |
| 结题报告、论文 | C 路线（对应子类） |
| 三期一致的指标口径与数据卡 | 本路线维护（项目档案） |
