# 课程论文与课设报告 · 子类判别与骨架（types）

> 证据来源：20 份样本（C-01…C-20，见 `_analysis/notes/course-papers/`，原件不入包）。
> **优先级铁律：用户直接要求 > 工作区已有模板（老师下发） > 本文默认。**

## 1. 子类判别表（先判类，再动工）

| 子类 | 判别信号 | 默认载体 | 骨架 | 样本 |
|---|---|---|---|---|
| **课程论文**（观点/理论/综述） | 平时/期末"小论文、课程论文、课程报告"；人文名（马原/党史/文明鉴赏）、数学课（泰勒/Riemann）、专业课观点文 | **LaTeX**（本包 uestcreport 吸收版）或按老师模板；Word 亦可 | 见 §2 各形态 | C-01/07/08/09/14/18/19 |
| **课程设计报告** | "课程设计、课设、大作业报告"，有仿真/实现内容 | **问一次：LaTeX 还是 Word** | 见 §2.5 | C-10/11 |
| **综合课程设计** | 明确说"综合课程设计"或对上附件7 | Word（附件7） | 见 §2.6 | C-16/17 |
| **结题报告** | "结题、项目收尾、Kaggle/项目结题" | LaTeX 或课程官方模板 | 见 §2.7 | C-02/20 |

## 2. 各形态骨架

### 2.1 思政类论文（C-08/09/19）

**封面三种**：
- 格式 A（Word 课程考核封面，C-08/09）：《课程名》期末考核论文 → 论文题目（主标+破折号副标）→ 教师姓名/学生姓名/学号填写行 → 分数/评语表（留空）。
- 格式 B（LaTeX，C-19）：二号黑体标题居中 → 五号宋体"电子科技大学 学院 专业 姓名" → maketitle 下居中一行"××课程论文"课程标注 → 摘要（黑体标签+宋体正文）→ 关键词。
- 仿学位论文封面（珠峰计划等，C-03/07）：电子科大 THESIS 双语封面+信息表——**老师给了封面模板就照抄**。

**骨架**：摘要（五句式：切入点→方法→梳理内容→研究发现→本文旨在）→ 关键词 3–5 → 正文 → 参考文献。
- **有章节型**（≥3000 字，C-08/19）：一、引言 → 二~四、论节（理论框架→案例/史实分析→历史逻辑/反思启示）→ 五、结语；子节用（一）（二）。
- **无章节型**（≈2000 字，C-09）：摘要后 6–7 段一气呵成，靠设问过渡（"那么，究竟什么是…？"）。
- **核心写法（三件套）**：观点—引用（领导人讲话/经典原著/教材，注明出处）—联系实际（历史案例/当下案例/**自身专业案例**——C-19 用生成式AI 结合马原是标杆）。
- 论证句式："第一，价值取向一致。第二，方法论上递进。第三，组织机制完善。"；挑战段"一是…二是…三是…"+对策逐条对应。
- 副标题范式："从'半条被子'到'精准扶贫'——群众路线的实践演进与当代价值"（意象锚点+破折号点题）。

### 2.2 观点型课程论文（C-01）

- 标题即观点（"X 的终点：从 A 到 B 的 C 重塑"）；可无参考文献、无图表。
- 骨架：摘要（观点先行，"然而，本文认为…"）→ 关键词 → 一、引言：背景与局限 → 二、现有方案的局限（编号矛盾）→ 三、核心观点（双小节展开）→ 四、挑战与思考 → 五、结论。
- 章节标题观点化；术语中英对照。

### 2.3 理论推导型（数学课，C-07/14）

- 摘要动机式（"课本上…并未给出证明。为了完善…本文将给出并证明…"）。
- 证明型骨架（仿学位论文格式时）：第一章 基础（定义/引理）→ 第二章 定理一证明（必要性/充分性）→ 第三章 定理二证明 → 参考文献；公式章内编号 (1-1)。
- 推导比较型（C-14）：1 引言 → 2 分型推导（2.1/2.2/2.3/2.4）→ 关系与比较。
- 数学行文规范："不妨设""由假设可知""当且仅当"；证明步骤编号；分类讨论穷举后收拢（C-11："y方胜利当且仅当 ty 无解"）。

### 2.4 学术综述型（C-03/04）

- 期刊格式（C-04）：标题+作者并列+（单位）→ 摘要+Abstract → 数字编号章节（分类框架→逐类介绍→总结与展望），引用密集。
- 仿学位论文格式（C-03）：双语封面→摘要页（罗马页码）→第一章 绪论（数学预备）→主体方法逐节（每节"估计式+解释+区别"）→其他方法→总结→参考文献（IEEE 风）。
- 高分综述要点：把多篇文献组织进一个统一数学框架（C-03 式(2-1)）。

### 2.5 课程设计报告（C-10/11 参照骨架）

- 封面：课程设计报告+题目+信息栏（课程名称/选题编号/工具/扩展选项/小组成员含学号）；页脚"第N页/共N页"。
- 九节+附录：一、课程设计任务（任务要求/总体流程引号链/**完成内容↔课程知识点映射表**）→ 二、问题建模 → 三、理论方法与算法设计 → 四、仿真/系统实现 → 五、结果与分析 → 六、遇到的问题与解决方法 → 七、总结与改进方向 → 八、详细分工 → 九、代码结构说明 → 附录（完整源码）。
- 数模作业变体（C-05/06/11/13）八段：摘要（按问题分条"针对问题一，本文采用…"）→ 关键词 → 问题重述（背景/重述）→ 问题分析 → 模型假设 → 符号说明（表）→ 模型的建立与求解（按问题分节，公式编号）→ 模型的评价（优点/普适性/检验）→ 附录代码。
- 团队要件：贡献比例声明（C-05"1:1:1"）、分工节。

### 2.6 综合课程设计（附件7，C-16/17）

- 三级标题（第一章/1.1/1.1.1）；中英双摘要+关键词；目录。
- 六章范式（现代规范版 C-17）：项目概述（背景/技术选型/**选型对比理由**/报告结构段）→ 系统架构设计 → 功能模块实现 → 关键技术源码 → 功能测试 → 总结与改进方向。
- **图表章内编号**："图2-1""表2.1"；代码以编号表格呈现。
- 素材合规声明（C-17："提示词均为个人原创""音频来源注明"）——AI 素材时代必写。
- 文风两极（C-16 范文口语化叙事 vs C-17 工程克制）：建议向 C-17 靠，绪论可保留文化/背景叙事（C-16 的象棋史写法适合文化类选题）。

### 2.7 结题报告（C-02/20）

- 十节骨架：1 题目概况 → 2 题目分析（PEAS/环境分类）→ 3 探索性数据分析 → 4 最新研究现状 → 5 项目结题进展情况 → 6 解题模型设计（技术点逐小节）→ 7 结题结果分析 → 8 结题主要问题分析（分层数据/模型/策略/推理）→ 9 拟改进措施（**与问题逐层对应**）→ 10 参与项目体会（第一人称）。
- 与开题/中期同项目时保持指标口径一致（P-07/P-06/C-02 三部曲实证）。

## 3. 摘要与关键词的形态学

| 形态 | 写法 | 样本 |
|---|---|---|
| 五句式（思政/观点） | 切入点→方法→内容→发现→旨在 | C-08 |
| 按问题分条（数模） | 针对问题一/二/三，各一句方法+结果 | C-06 |
| 四句式（综述） | 首先…其次…最后…"重点叙述"声明 | C-03/04 |
| 技术清单式（综合课设） | 背景一句+架构+规模+测试+开源声明 | C-17 |
| 动机式（理论） | 课本缺口→本文补全什么 | C-07/14 |

关键词 3–6 个，分号或逗号分隔（跟模板）；中英双摘要只在模板要求时给。
