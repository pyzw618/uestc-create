# 课程论文与课设报告 · 交付自检清单（checklist）

> A 判别与骨架 / B 内容 / C 引用 / D 格式 / E 合规。

## A. 判别与骨架

- [ ] 子类判别正确（课程论文/课设报告/综合课设/结题/数模），载体（LaTeX/Word）经用户确认或按模板
- [ ] 骨架与老师模板逐节对齐（封面格式、章节编号风格：中文"一、"/"第一章"/数字"1"）
- [ ] 封面字段齐全且与 `config/user.yaml`/用户提供信息一致；教师姓名按要求填写；分数评语栏留空
- [ ] 中英双摘要仅按模板要求提供；目录与正文标题逐条一致（无残留、无错位）
- [ ] 数模类：模型假设/符号说明/按问题分节求解/模型评价/附录代码 齐全；小组报告有分工与贡献声明

## B. 内容

- [ ] 摘要四要素齐、无引用编号与图表引用、无未解释缩写；数模摘要含数值结果
- [ ] 引言漏斗完整；每节有观点句与证据；案例具体（时间/地点/数字），无"许多地方"式含糊
- [ ] 思政类：观点—引用—联系实际三件套每节可辨；联系自身专业至少一处；结尾落到自身行动
- [ ] 结论不复述方法；理论类给出明确条件/关系式
- [ ] 字数达标（老师要求 ±10%）；无注水段与重复段
- [ ] 术语首次出现有解释；无连续名词堆砌；"第一/第二"仅用于真并列

## C. 引用

- [ ] 每条参考文献真实可查；文中编号与文末条目一一对应；格式统一 GB/T 7714（或模板要求格式）
- [ ] 直接引语逐字核对并加引号；领导人著作/讲话引用准确
- [ ] 综述类引用覆盖所综述的主要工作；英文条目格式一致

## D. 格式

- [ ] LaTeX：编译零 error；交叉引用无 "？?"；中文章节号/标题层级符合模板；页码（摘要罗马/正文阿拉伯）正确
- [ ] 版面：逐页渲染后正文底部无大段空白（>1cm 须查断页质量，见 writing.md §6），目录与正文之间无整页空白
- [ ] Word：标题用样式、正文缩进 2 字符、行距按模板；图表编号连续且被正文引用；公式呈现方式全文一致
- [ ] 图表：图题图下、表题表上；综合课设用章内编号（图2-1/表2.1）
- [ ] 页脚页码/页眉按模板；封面不显示页码

## E. 合规

- [ ] 全文与文件名无真实姓名学号（除用户本人信息按封面要求填写外）
- [ ] AI 素材（文生图/代码/文本）使用已按课程要求声明（方式+范围）
- [ ] 音频/图片素材来源注明；开源链接有效
- [ ] 账号名、本机路径、评测凭据已脱敏
- [ ] 交付新文件；编译中间产物清理（.aux/.log 等不入交付）
